# Licencje assetów

Każdy asset (grafika, dźwięk, muzyka, font) wykorzystany w projekcie musi być udokumentowany w tym pliku.

## Wymagania

- **Zero ripów** — żadnych assetów wyciętych z innych gier komercyjnych
- Wyłącznie: CC0 / CC-BY / kupione licencje komercyjne / autorskie
- Każdy wpis: ścieżka, źródło, autor, licencja, data dodania

## Wpisy

_Brak — projekt w fazie scaffolda._

### Szablon wpisu

```
- **Ścieżka:** assets/sprites/hope_idle.png
  **Źródło:** https://opengameart.org/...
  **Autor:** ...
  **Licencja:** CC0 / CC-BY 4.0 / Aseprite Asset Pack (komercyjny zakup)
  **Data:** 2026-04-26
  **Notatki:** ...
```

## Wizerunki / historie realnych dzieci

Każdy taki asset wymaga **pisemnej zgody rodziców** zarchiwizowanej w `docs/legal/zgody/`. Numer dokumentu zgody należy podać w polu `Notatki`.
